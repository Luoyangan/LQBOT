# LQBOT

**纯 Go · 单二进制 · 开箱即用的 QQ 机器人**

LQBOT 基于 QQ 开放平台，用 Go 编写，编译产物只有一个可执行文件——无需 Node.js、Python、数据库服务或 CGO，下载、运行、打开浏览器就能用。

内置 Web 管理后台，**99% 的操作可视化**：机器人账号接入、规则与变量编排、事件处理、群管理、定时推送、素材库、开放 API 都可在页面中完成，几乎不用写代码、不用改配置文件。同时内置 AI 助手，填入任意 OpenAI 兼容模型的服务地址与 Key，即可让机器人在群聊、私聊中自动回复。

## 特性

- **单二进制交付**：前端资源通过 `go:embed` 打进二进制，没有独立的前端构建与部署步骤，也没有外部运行时依赖。
- **AI 智能助手**：OpenAI 兼容模型接入，支持私聊 / 群共享 / 群成员独立三种记忆维度、图片识别与语音转写、思考模式、联网搜索与网页抓取、跨会话长期记忆；回复支持 Markdown 与图文、按钮、@成员等富文本组件。
- **可视化运营**：向导式初始化（数据库 → 管理员密码），之后全部配置、规则、群管理都在 Web 后台点选完成。
- **规则引擎 + 变量引擎**：按事件匹配规则，串联消息回复、群管理动作、HTTP 请求与 AI 调用等动作，支持多轮会话收集。
- **多账号与多通道**：同时管理多个机器人账号，覆盖 QQ 单聊、群聊与频道三类会话。
- **多数据库后端**：SQLite（默认，纯 Go 驱动）/ MySQL / PostgreSQL / SQL Server，另有 Redis、MongoDB 可选接入。
- **开放 API**：`/openapi/v1` 提供发消息、查状态、主动推送接口，Bearer Token 鉴权 + 限频 + 权限范围控制。
- **可观测与安全**：实时事件流、事件日志、操作审计、系统资源仪表盘与日志按天轮转；内置登录锁定、CSRF、安全响应头、AES-GCM 凭据加密与出站安全出口。

## 支持平台

| 平台 | 形态 | 说明 |
| --- | --- | --- |
| Windows | 单个 `.exe` | 双击即运行 |
| Linux | 可执行文件 | amd64 / 386 / arm / arm64 |
| Android | APK | 内置 Go 内核的前台服务，控制台查看日志，浏览器打开管理后台 |

> macOS 暂未支持。

## 快速开始

1. 获取对应平台的发布产物。
2. 运行程序：Windows 双击 `LQBOT-*.exe`，Linux 执行 `./LQBOT-*`。
3. 浏览器打开 <http://127.0.0.1:4789/admin>，按向导填写数据库连接（本机试用选 SQLite 即可）并设置管理员密码。
4. 进程重启后登录后台，添加机器人账号并配置事件订阅，即可开始使用。
5. 想启用 AI：在「机器人 → AI 助手」填写 OpenAI 兼容服务地址、模型与 API Key。
